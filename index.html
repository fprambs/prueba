AustroDrone

Vuela un cuadricóptero, atraviesa los aros amarillos y explora el mapa.

  • W / S — Subir / bajar gas (empuje vertical)
  • ↑ / ↓ — Inclinar adelante / atrás (cabeceo)
  • ← / → — Inclinar izquierda / derecha (alabeo)
  • A / D — Girar sobre su eje (guiñada)
  • Shift — Impulso extra
  • Espacio — Autoestabilizar (nivelar)
  • C — Cambiar cámara (geográfica / FPV / cinemática)
  • [ / ] — Inclinar el gimbal de la cámara FPV
  • R — Reiniciar posición
  • Joystick ⬅️ — Arriba/abajo: gas · Izq/der: guiñada
  • Joystick ➡️ — Arriba/abajo: cabeceo · Izq/der: alabeo
  • ⚖️ — Mantén pulsado para autoestabilizar
  • ⚡ — Mantén pulsado para impulso extra
  • 📷 — Cambiar cámara   ⟲ — Reiniciar
  • Deslizador GIMBAL — Arrastra para inclinar la cámara FPV
